# libSceFreeTypeOt

## add Functional

- [Guest pointer copies](../../../core/libs/prx/libSceFreeTypeOt/Export.cpp) (libSceFreeTypeOt) - the non-forwarded exports in `Export.cpp`, `Stream.cpp` and `src/` read and write guest records, strings and output pointers through `GuestCopyIn_nid_no_patch`, `GuestCopyOut_nid_no_patch` and `GuestWritable_nid_no_patch` while preserving `errno`, throwing when a guest pointer is unreadable or unwritable (except `FT_Outline_Done_Internal` and `FT_Outline_New_Internal`, which return `Invalid_Argument` 0x06 when `outline` or `anoutline` cannot be read or written, and `FT_Stream_ReadFields`, which returns `Invalid_Argument` 0x06 when `stream` is unreadable); this is a host-safety fallback and console fault behavior is unverified.

## change [FT_Raccess_Get_HeaderInfo, FT_Raccess_Get_DataOffsets]

- [FT_Raccess_Get_HeaderInfo, FT_Raccess_Get_DataOffsets](../../../core/libs/prx/libSceFreeTypeOt/src/Raccess.cpp) (libSceFreeTypeOt) - console prototypes and FreeType version equivalence are unverified. Both follow 2.4.12 [ftrfork.c](https://github.com/freetype/freetype/blob/cecf93ef90c660a8b0b45e5adbbfb5ea443fb6b9/src/base/ftrfork.c#L49-L237) and read only `memory` from the library. `FT_Raccess_Get_DataOffsets` takes the seven arguments of 2.4.11-2.5.2; from 2.5.3 `sort_by_res_id` precedes `offsets`. Header fields with the top bit set, overflowing `FT_Long` sums, and equal resource IDs with different offsets throw; 2.13.3 adds overlap, stream size and count checks 2.4.12 lacks. Null or inaccessible guest pointers are checked with `GuestCopyIn_nid_no_patch`, `GuestCopyOut_nid_no_patch` and `GuestWritable_nid_no_patch` preserving `errno` and throw via `NotImplemented_nid_no_patch` as a host-safety fallback; console fault behavior is unverified.

## change [FT_Raccess_Guess]

- [FT_Raccess_Guess](../../../core/libs/prx/libSceFreeTypeOt/src/Raccess.cpp) (libSceFreeTypeOt) - the console prototype and `FT_CONFIG_OPTION_MAC_FONTS` build option are unverified. The nine rules, their order and six-argument form follow 2.4.12 [ftrfork.c](https://github.com/freetype/freetype/blob/cecf93ef90c660a8b0b45e5adbbfb5ea443fb6b9/src/base/ftrfork.c#L357-L812), which enables `FT_CONFIG_OPTION_MAC_FONTS` by default; disabled, every rule would return `Unimplemented_Feature`. Names come from library memory and AppleDouble probes open files through `FT_Stream_New`, resolving like libc paths. Null or inaccessible `library`, `library->memory`, `baseName`, `newNames`, `offsets`, `errors` or non-null `stream` pointers are checked via `GuestCopyIn_nid_no_patch`, `GuestCopyOut_nid_no_patch` and `GuestWritable_nid_no_patch` preserving `errno` and throw via `NotImplemented_nid_no_patch` before any rule runs as a host-safety fallback; console fault behavior is unverified.
